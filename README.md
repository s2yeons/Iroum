# Iroum 이로움

어르신이 받을 수 있는 혜택을 놓치지 않도록 돕는 복지 도우미입니다.
어려운 공공 안내문을 큰 글씨와 쉬운 말로 바꾸고, 나에게 맞는 복지 제도를 찾아 준비 서류와 신청 방법까지 체크리스트로 안내합니다.

> 제도 정보는 공식 자료에서 가져오고, AI는 그 내용을 쉽게 설명하는 역할만 맡습니다.
> 앱은 "받을 수 있어요"라고 단정하지 않고, 최종 결정은 주민센터에서 한다고 안내합니다.

## 기능

| 기능 | 설명 | AI 호출 |
|---|---|---|
| 지원금 찾기 | 질문 5개(나이·사는 곳·가구·형편·받는 지원) → 공식 자료 기반 규칙 필터 | 0회 |
| 안내문 쉽게 읽기 | 붙여넣기 / 사진(브라우저 OCR) / PDF → 쉬운 설명·조건·서류·순서·기한·문의처 | 문서당 1회 |
| 신청 체크리스트 | 제도별 준비물을 체크, 진행 상태는 기기에만 저장 | 0회 |
| 음성 안내 | 모든 화면 "읽어 주세요", 자동 읽기·빠르기 조절 (Web Speech API) | 0회 |
| 행정용어 사전 | 어려운 낱말을 누르면 쉬운 뜻 (32개) | 0회 |
| PWA | 홈 화면 설치, 인터넷이 끊겨도 제도 안내·체크리스트 사용 | - |

### 잘못된 정보를 막는 장치

1. **근거 대조** — AI가 적은 모든 항목의 `source_quote`가 원문에 실제로 있는지 서버에서 비교하고, 없으면 화면에서 뺍니다 ([src/lib/verify.ts](src/lib/verify.ts)).
2. **숫자 지킴이** — 쉬운 설명에 나온 금액·날짜·나이가 원문에 없으면 그 문장을 뺍니다.
3. **공식 기준 별도 표시** — 안내문에서 제도명이 확인되면 공식 자료의 자격 기준을 따로 보여 줍니다.
4. **AI 없는 모드** — AI를 쓸 수 없으면(키 없음·사용량 초과·오프라인) 원문 문장을 그대로 골라 항목별로 나눕니다 ([src/lib/rule-simplify.ts](src/lib/rule-simplify.ts)).

## 시작하기

```bash
npm install
npm run dev        # http://localhost:3000
```

AI 쉬운 말 변환을 쓰려면 `.env.local`에 Gemini API 키를 넣습니다. 없으면 AI 없는 모드로 동작합니다.

```
GEMINI_API_KEY=...
# 선택: 기본값 gemini-3.8-flash
GEMINI_MODEL=...
```

## 구조

```
src/
  app/
    page.tsx              첫 화면
    find/                 지원금 찾기 (질문 → 결과)
    benefits/[id]/        제도 상세 + 체크리스트
    read/                 안내문 쉽게 읽기
    voice/                음성 안내 설정
    api/simplify/         AI 변환 (문서당 1회, 해시 캐시, 근거 대조)
  data/
    welfare.json          제도 12개 (공식 기준·서류·장소·문의처·출처·확인일)
    glossary.json         행정용어 사전
  lib/                    규칙 필터, 근거 대조, AI 없는 모드, OCR·PDF 추출
public/sw.js              서비스 워커 (오프라인)
```

## 제도 데이터 갱신

[src/data/welfare.json](src/data/welfare.json)의 각 제도에는 출처 URL과 확인일(`checked_at`)이 있습니다.
기준 금액은 해마다 바뀌므로 매년 공식 자료와 다시 대조하고 확인일을 고쳐 주세요.

## 배포 (Vercel)

일반 Next.js 앱과 같이 배포하면 PWA도 함께 동작합니다 (Vercel이 HTTPS를 제공).
배포 후 화면이 바뀌었다면 [public/sw.js](public/sw.js)의 `VERSION`을 올려 예전 저장본을 지우세요.

PWA 아이콘을 다시 만들려면: `npx tsx scripts/gen-icons.tsx`
